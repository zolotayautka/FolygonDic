# <img src="https://github.com/zolotayautka/FolygonDic/blob/main/FolygonDic/Assets.xcassets/AppIcon.appiconset/icon.png" width="30"> FolygonDic

**A vocabulary learning app where you can create and study your own word lists**

## Key Features

### 📝 Word Management
- **Add/Edit/Delete Words**: Freely register words you want to learn
- **Part of Speech Classification**: Categorize into 7 parts of speech - particle, preposition, noun, verb, adjective, adverb, and others
- **Multi-field Support**: Store detailed information including word, kanji, meaning, and notes
- **Real-time Search**: Search across all fields including word, meaning, kanji, and notes

### 🎯 Learning Features
- **Text-to-Speech (TTS)**: Listen to pronunciation of registered words in your selected language
- **Study Count Tracking**: Automatically record the number of times each word has been studied
- **Daily Notifications**: Receive study reminders every day at noon
- **Learning Statistics**: Visualize word count by part of speech with pie charts

### ⌚ Apple Watch Integration
- Send study words from iPhone to Watch
- Sync study progress from Watch to iPhone
- Automatic learning record updates

### 🌍 Multilingual Support
- **Korean** (ko)
- **Japanese** (ja)
- **English** (en)
- Customized TTS voice support for each learning language

### 💾 Data Management
- SQLite-based local database
- Fully functional offline
- Reliable data storage and management

### 📱 Multi-platform
- **iOS** - iPhone optimized UI
- **iPadOS** - Split View support for tablets
- **macOS** - Desktop environment support
- **watchOS** - Apple Watch app available

## Tech Stack
- **Language**: Swift, SwiftUI
- **Database**: SQLite3
- **Frameworks**: AVFoundation (TTS), UserNotifications, WatchConnectivity
- **Minimum Requirements**: iOS 14.0+

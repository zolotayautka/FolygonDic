# <img src="https://github.com/zolotayautka/FolygonDic/blob/main/FolygonDic/Assets.xcassets/AppIcon.appiconset/icon.png" width="30"> FolygonDic

**자신만의 단어장을 만들어 학습하는 어휘 학습 앱**

## 주요 기능

### 📝 단어 관리
- **단어 추가/수정/삭제**: 학습하고 싶은 단어를 자유롭게 등록
- **품사별 분류**: 조사, 전치사, 명사, 동사, 형용사, 부사, 기타 7가지 품사로 분류
- **다중 필드 지원**: 단어, 한자, 의미, 비고 항목을 포함한 상세 정보 저장
- **실시간 검색**: 단어, 의미, 한자, 비고 등 모든 필드에서 검색 가능

### 🎯 학습 기능
- **음성 재생(TTS)**: 등록된 단어를 선택한 언어로 발음 들을 수 있음
- **학습 횟수 추적**: 각 단어별 학습 횟수를 자동으로 기록
- **일일 알림**: 매일 정오에 학습 알림을 받을 수 있음
- **학습 통계**: 파이 차트로 품사별 단어 수를 시각화

### ⌚ Apple Watch 연동
- iPhone에서 학습할 단어를 Watch로 전송
- Watch에서 학습한 내용을 iPhone으로 동기화
- 학습 기록 자동 업데이트

### 🌍 다국어 지원
- **한국어** (ko)
- **일본어** (ja)
- **영어** (en)
- **러시아어** (ru)
- **스페인어** (es)
- **중국어** (zh)
- 학습 언어별 맞춤 TTS 음성 지원

### 💾 데이터 관리
- SQLite 기반 로컬 데이터베이스
- 오프라인에서도 완전 동작
- 안정적인 데이터 저장 및 관리

### 📱 멀티 플랫폼
- **iOS** - iPhone 최적화 UI
- **iPadOS** - 태블릿용 Split View 지원
- **macOS** - 데스크톱 환경 지원
- **watchOS** - Apple Watch 앱 제공

## 기술 스택
- **언어**: Swift, SwiftUI
- **데이터베이스**: SQLite3
- **프레임워크**: AVFoundation (TTS), UserNotifications, WatchConnectivity
- **최소 요구사항**: iOS 14.0+
